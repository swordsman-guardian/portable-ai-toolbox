便携 AI 工具箱 v0.2.0-alpha.1（源码包）

本说明对应 v0.2.0-alpha.1 源码包。源码包不含 Node、Git、Python、uv、CC Switch、Claude Code、WebView2 等第三方运行程序，也不是可直接使用的 U 盘镜像。完整步骤、限制与验证范围请先阅读 docs\首次使用.md。

当前目标环境为 Windows 10/11 x64 和 Ubuntu 24.04 x64。Windows 11 Home x64（版本 10.0.26200）与 PowerShell 5.1 的独立空源码目录准备已通过；Windows 10 尚无实体机验证结果。Linux 完整准备脚本以普通用户身份在 WSL2 Ubuntu 24.04 x64 重跑成功，冷准备及 WSLg 图形启动已验证。WSL 当前未启用 AppArmor，不能代表实体 Ubuntu 的 AppArmor 授权体验。

准备与日常使用

Windows：准备机需要 Windows PowerShell 5.1 和 Visual Studio“使用 C++ 的桌面开发”工作负载。把源码 ZIP 顶层目录中的内容平铺到一个全新的目录，运行 准备Windows.cmd。入口先检查条件，再联网下载、校验和构建，需预留数 GB 空间。独立空源码目录准备入口已成功运行；本次 CC Switch ZIP 使用本轮从官方 Release 获取的缓存并经入口固定 SHA-256 复核。匿名下载通道没有完整下载该 ZIP，首次准备速度仍取决于网络。准备成功后，把准备目录内全部文件和文件夹复制到 U 盘根目录，确保 AI.cmd 与 scripts\ 同层。每个新源码目录只准备一次；不要在已有个人配置、保险箱或会话的目录重跑。

Linux：面向 Ubuntu 24.04 x64，先将源码 ZIP 顶层目录中的内容平铺到 U 盘根目录，然后以普通用户运行：

  ROOT="/media/$USER/TOOLBOX"
  bash "$ROOT/scripts/bootstrap-linux.sh" "$ROOT"

请将 TOOLBOX 替换为实际盘名。若 AppArmor 限制隔离启动，程序说明后会由 sudo 在终端提示本机管理员密码（不是 U 盘主密码）；可按 Ctrl+C 取消。工具箱不读取或保存管理员密码。

第三方下载优先使用官方来源；若使用镜像，也必须通过官方固定 SHA-256 校验，文件大小不能代替哈希校验。

首次配置与日常运行

Windows：在准备好的 U 盘上打开 AI设置.cmd → 10「CC Switch 接入」→ 8「解锁 / 打开原生 CC Switch（隔离联网）」；按提示在本机创建主密码，并在 CC Switch 中添加供应商配置。保持 CC Switch 会话窗口运行，再从另一个终端或 AI.cmd 启动 Claude。

Linux：默认工作目录是 U 盘根目录下的 workspace/，不存在时会创建；菜单 2 可输入其他项目目录，回车使用默认目录。Windows 首次使用默认 workspace/；已有本机记忆目录时，回车会沿用上次目录。

主密码和供应商 API 密钥只在本机工具界面输入，不要发送到聊天或提交到仓库。初始化不要求发送真实 API 请求；主动执行连通性测试才会向供应商发请求，可能产生费用。使用结束后正常退出并等待保存完成，再锁定 CC Switch 并安全弹出 U 盘。强制断电、终止进程或拔盘可能中断保存或清理。
