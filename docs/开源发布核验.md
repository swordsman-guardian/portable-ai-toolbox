# 首次公开发布核验

本页记录 `v0.2.0-alpha.1` 的发布范围，不把自动化检查等同于外部用户的实体机验收。

## 公开内容

公开仓库和源码附件只包含经审核的项目代码、测试、无密钥模板和文档。项目原创内容使用根目录的 MIT 许可证，第三方许可另见[第三方许可与公开发布](第三方许可与公开发布.md)。

`config/`、`sessions/`、`logs/`、`cache/`、`workspace/`、下载好的运行时、加密保险箱和恢复包均未纳入源码白名单。加密后的个人数据也不上传。公开附件由已提交的 Git 内容生成，不打包当前 U 盘上的运行目录。

## 历史与旧附件

发布前对所有已取得的 Git 引用和完整提交历史进行 Gitleaks 扫描，不只检查当前文件；同时核对历史中的文件路径，确认没有提交个人运行目录或程序二进制。历史说明中的测试凭据和例子不能替代对真实配置的检查。

旧 `v0.1.0` 的小型启动修复附件经过摘要核对和解包扫描。旧完整程序包没有作为本次公开附件重新发布，保留为非公开草稿；未对其内容做本次完整扫描，也不将其视为已经完成公开再分发许可审查。

## 首次准备与验证

Windows 准备验证使用独立的新源码目录，不复制已有 U 盘的配置、保险箱或已下载程序；Linux 使用独立的 Ubuntu 24.04 WSL 目录。测试不需要真实 API 密钥，不执行付费模型请求。

两套环境的完整准备入口均已成功运行。Windows 的 CC Switch ZIP 因下载较慢，由本轮 `gh` 从官方 Release 获取后作为固定哈希缓存交给准备入口复核；这不代表匿名 API 的完整下载已通过。Windows 还验证了首次准备后的回执复核不会改动空配置。Linux 完成真实运行时、隔离执行与 WSLg 图形窗口启动检查。

具体准备结果、测试环境和已知限制以[版本说明](Release-v0.2.0.md)及该版本对应的 GitHub Actions 检查为准。AppArmor 的真实临时策略加载与撤销在一次性 GitHub Linux 测试机上验证，本机 WSL 的普通测试不能证明该分支。

文档由执行代理以首次使用者视角独立走读，但不称为外部真人试用。此版本为 alpha，尚不保证所有 Windows 策略、Linux 发行版、桌面环境或异常拔盘情形都可用。

## 公开附件核对

`scripts/build-public-release.ps1` 从干净的已提交版本导出源码。后续文件枚举和归档都使用捕获的提交 SHA；已在独立测试仓库中模拟构建期间 HEAD 改变，确认归档仍取自原提交。脚本拒绝个人数据根目录、程序二进制、数据库、符号链接和子模块，并核对导出文件数量和路径。附件包括源码 ZIP、逐文件摘要清单 `release-manifest.json` 和 `SHA256SUMS.txt`。

清单中的 `sourceCommit` 对应此次发布源码；`containsThirdPartyBinaries` 为 `false`。发布前解包再扫描，并核对这两个附件的 SHA-256。源码下载后还需按[首次使用说明](首次使用.md)联网准备依赖。
