Third-party components used by the toolbox

The v0.2.0-alpha.1 PUBLIC SOURCE release contains original toolbox source and
license texts, not the third-party binaries listed below. Preparation downloads
programs from official sources first, with pinned-hash-verified mirrors where
supported, for the user's own use. This inventory also
describes the older private MVP bundle; it is not permission to redistribute it.

All bundled third-party components retain their own licenses and notices.
This toolbox does not grant rights beyond those supplied by each component.

Node.js / npm: runtime/node/LICENSE and bundled package LICENSE files
  https://nodejs.org/ ; https://github.com/npm/cli
Git for Windows: runtime/git/LICENSE.txt and bundled component notices
  https://gitforwindows.org/
Python / pip: runtime/python/LICENSE.txt and Lib/site-packages license files
  https://www.python.org/ ; https://github.com/astral-sh/python-build-standalone
uv: licenses/uv-LICENSE-APACHE and licenses/uv-LICENSE-MIT
  https://github.com/astral-sh/uv
CC Switch v3.20.4: licenses/CC-Switch-LICENSE; upstream official EXE unchanged
  https://github.com/farion1231/cc-switch/tree/v3.20.4
  Upstream source: https://github.com/farion1231/cc-switch/archive/refs/tags/v3.20.4.zip
Claude Code 2.1.285: LICENSE files in tools/harness/claude/slots/2.1.285/node_modules
  https://www.npmjs.com/package/@anthropic-ai/claude-code
Microsoft Edge WebView2 Fixed Version Runtime: bundled component notices
  https://developer.microsoft.com/microsoft-edge/webview2/
  https://www.microsoft.com/en-us/legal/terms-of-use

The native isolation adapter is toolbox source under scripts/; it is not a modified
CC Switch executable. The public source release-manifest.json records source
file hashes only; preparation records the downloaded dependencies separately.
